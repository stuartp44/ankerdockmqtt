Broker settings

Passwords are encrypted using macOS Keychain or Windows DPAPI. Use mqtts:// for encrypted transport. Save settings before starting.

Polling pauses and the dock handle closes when MQTT disconnects. It resumes only after the configured broker accepts a connection. This is broker-based gating, not a Wi-Fi SSID allowlist.
